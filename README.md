# pairwise-buff-stacking

同一 buff 叠到第五层后攻速反而变慢，叠层规则把乘区当成加区，五次 1.1 倍被算成 1.5 倍；刷新持续时间时把剩余时间清零，高层 buff 永远差半秒；属性快照在施加时固化，后面换装备不再影响 buff 效果；上限判断在客户端做，服务器收到第六层后按上限截断但客户端显示五层；驱散只移除一层，负面 buff 的持续时间却在每帧重置；角色死亡时只清正面 buff，复活后中毒层数还在；叠层 tick 按帧累加，不同帧率下伤害跳数不同；免疫判定在叠层之后，刚上的 buff 当帧就触发一次伤害；网络同步只发层数不发剩余时间，客户端倒计时和服务器差两秒；多个来源的同一 buff 共用 id，驱散时把别人的 buff 一起清掉。gameplay/buff_stacking.py 是核心，tests/test_buff_stacking.py 15个红。要修的是：乘区加区分离；刷新保留剩余时间；属性动态求值；服务器权威层数；驱散按来源；死亡清全部；tick 按时间；免疫先于叠层；同步剩余时间；buff 实例独立 id。

## 运行

```bash
python -m pytest tests -q
```
